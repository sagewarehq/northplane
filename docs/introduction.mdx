# What is Northplane?

[Headscale](https://headscale.net) is a self-hosted implementation of the
Tailscale control server: it lets Tailscale clients form a private network
without Tailscale's servers. It doesn't come with a web interface, and Northplane
is one, modeled on Tailscale's admin console.

<Figure

  light={previewLight}
  dark={previewDark}

Northplane manages:

- **Machines**: rename them, change their owner, approve routes and exit nodes,
  manage tags, and expire or remove them
- **Users and auth keys**, including what each person can do in Northplane
- **Access control**: edit the ACL policy visually or as a file
- **DNS**: the tailnet name, Magic DNS, nameservers, search domains and records

It also adds features Headscale doesn't have:

- **Single sign-on** through any OpenID Connect provider, or through a
  reverse proxy, with roles for each person
- **Browser SSH** into any machine on the tailnet, with no client installed
- **The Northplane Agent**, which shows each machine's Tailscale version, OS and
  connectivity
